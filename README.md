# 🧩 Exercism Journey - Java & Python 🚀

Bienvenue dans mon laboratoire personnel de résolution de problèmes ! Ce dépôt contient mes solutions aux défis (tracks) proposés par [Exercism](https://exercism.org/).

## 🎯 Objectifs Pédagogiques

À travers ces exercices, je m'efforce de :
* **Appliquer les principes SOLID** : Même sur de petits algorithmes.
* **Optimiser la Clean Code** : Écrire du code lisible, pas seulement fonctionnel.
* **Maîtriser les bibliothèques standard** : Utiliser la puissance native du langage sans dépendances externes.
* **Améliorer mon anglais technique** : Exercism étant en anglais, cela m'aide dans mon objectif de fluidité linguistique.
